# 東門國小家長會・營養午餐試菜紀錄

純靜態網站，用 GitHub Pages 發佈。**每天更新不需要手改程式或 JSON**，使用 `admin.html` 更新工具即可。

## 每天怎麼更新（約 2 分鐘）
1. 開啟 `https://你的帳號.github.io/repo名稱/admin.html`（更新工具，建議只給幹部知道網址）。
2. **貼上試菜文字**：把 LINE 裡代表的回報整段貼進去，按「解析文字」。一次貼多位代表、或整份 LINE 匯出文字都可以（會依日期自動分開）。解析後可直接修改班級與內容。
3. **選照片**：一次選多張，工具會自動縮小，只拍餐點。
4. **有問題才填**：在第 3 區填標題、家長反映摘要、營養師回覆。還沒回覆就留空，會標示「追蹤中」；等營養師回覆後，在同一區展開該則補上回覆即可。
5. 按「下載更新包」，解壓縮後，到 GitHub repository 按 **Add file → Upload files**，把 `data` 和 `img` 兩個資料夾拖進去，按 Commit changes。
6. 等 1–2 分鐘網站就更新。**下次使用工具前也要先等網站更新**，不然會讀到舊資料。

> 工具只在你的瀏覽器裡運作，不會上傳任何資料；真正發佈是步驟 5 的上傳。

## 發佈到 GitHub Pages（第一次）
1. 建立新的 repository。
2. 把本資料夾所有檔案（含 `.nojekyll`、`data/`、`img/`、`admin.html`）上傳到根目錄。
3. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save。

## 注意事項
- 公開 repository 的所有檔案與歷史紀錄都是公開的，上傳前請確認內容與照片已審核；已刪除的照片仍可能留在歷史中。
- `admin.html` 也會公開在網址上，但它只能產生檔案、無法修改網站。
- LINE 匯出文字只會抓到訊息裡含「試菜／試吃」的回報；沒有這兩個字的補記錄（例如只寫「補記錄在此」），請單獨貼上並確認班級。
- 手機 iPhone 選照片若出現 HEIC 無法讀取，請改選「最相容」格式或截圖後上傳。
- 本機直接雙擊打開網頁讀不到資料，請用 GitHub Pages 網址預覽。

## 新學期
複製 `data/115-1.json` 為 `data/115-2.json`，改 `id`、`name`、`months`（例如 `["02","03","04","05","06"]`），清空 `days` 與 `qa`，再把 `"115-2"` 加進 `data/semesters.json`。

## 公開前檢查
- 只顯示班級，不放家長姓名、LINE 暱稱與對話原文。
- 照片沒有人臉、名牌、班級座位。
- 營養師與學校的回覆已取得同意公開。
- 不放廠商名稱、未證實的傳言或個案資料。
